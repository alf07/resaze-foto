# Image Crop Tool

**Утилита на Go для пакетной обрезки изображений с генерацией JSON-аннотаций.**

Предназначена для быстрой подготовки датасетов для задач компьютерного зрения и машинного обучения. Позволяет обработать тысячи изображений за считанные секунды, автоматически обрезая их по заданной области интереса (ROI) и создавая JSON-разметку для дальнейшего использования.

## 🎯 Для чего это нужно

- **Подготовка ML-датасетов** — автоматическая обрезка и аннотирование изображений для обучения нейросетей.
- **Пакетная обработка** — за один запуск обрабатываются все изображения в папке.
- **Универсальность** — работает с любыми форматами (JPEG, PNG, BMP, WEBP).
- **Интеграция** — сгенерированные JSON-аннотации можно сразу использовать в тренировочных пайплайнах.

## ⚡ Возможности

- ✅ **Пакетная обработка** — все изображения в папке обрабатываются автоматически.
- ✅ **Обрезка по ROI** — задайте координаты (x, y, width, height) и получите обрезанные изображения.
- ✅ **Генерация JSON-аннотаций** — для каждого изображения создаётся JSON с координатами обрезки, размерами и метаданными.
- ✅ **Высокая производительность** — написан на Go, обрабатывает тысячи файлов за секунды.
- ✅ **Простота использования** — одна команда в терминале.

##  Требования
- Go 1.16
