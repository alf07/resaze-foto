# Image Crop Tool

Простая утилита на Go для пакетной обрезки изображений.

## Возможности
- Пакетная обработка всех изображений в папке
- Обрезка по заданным координатам (ROI)
- Генерация JSON-аннотаций для дальнейшего использования (например, для ML-датасетов)

## Использование
```bash
go run main.go ./input ./output 100 200 300 400
